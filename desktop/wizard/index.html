Welcome

Reggia is a personal AI chat with Notion-backed long-term memory and local SQLite for active items. This 5-minute setup connects it to your accounts.

What you'll need

  • Docker Desktop installed and running.
  • A DeepSeek API key (free signup at platform.deepseek.com).
  • A Notion account and a page Reggia can use as a parent for its memory pages.

Docker Desktop

Reggia runs its chat agent inside a Docker container for security isolation. Docker Desktop must be installed and running.

Checking…

DeepSeek API key

The chat agent uses DeepSeek's Anthropic-compatible API. Get a key at platform.deepseek.com/api_keys.

Notion integration

  1. Open notion.so/my-integrations and click New integration.
  2. Name it Reggia, pick your workspace, choose type Internal.
  3. Under Capabilities, confirm Read content, Update content, and Insert content are checked.
  4. Copy the Internal Integration Secret (starts with secret_ or ntn_) and paste it below.

Parent page

Reggia will create 5 sub-pages (Work, Research, Intellectual, Personal, Index) under a parent page you provide. Pick or create any Notion page to use as the home.

Important: open that page in Notion, click the ··· menu → Connections → add the Reggia integration. Without this step, page creation will fail.

Create memory pages

About to create 5 sub-pages under your parent page.

  • Research
  • Intellectual
  • Personal
